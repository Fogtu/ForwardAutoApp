# Обновление v3: заявки с подтверждением, календарь, отзывы, аккаунты админов

Архив кладётся **поверх проекта** (пути внутри совпадают с репозиторием). Согласитесь на замену файлов.

## Что нового

**Заявки и аренда**
- Заявка создаётся со статусом «На рассмотрении» и **не блокирует машину**. Машина закрепляется после одобрения.
- Календарь занятости на странице машины и в форме заявки; бронь на будущие даты. Пересечение дат проверяется на сервере и при одобрении.
- В Telegram-уведомлении кнопки «Одобрить / Отклонить» (новая функция `telegram-webhook`).
- Завершение аренды: у просроченной одобренной заявки в админке кнопка «Срок вышел — завершить». При завершении `rents` +1 (при откате статуса −1).
- Новые статусы: `pending`, `rejected` (+ прежние `active` = «Одобрена», `completed`, `cancelled`).

**Каталог:** фильтры по классу, точке выдачи, числу мест, «только свободные»; сортировка по скорости и залогу; бейдж «В аренде»; избранное (`/favorites`) и сравнение до 3 машин (`/compare`) на localStorage.

**Клиенту:** статус по номеру (`/status`), отзывы после завершённой аренды (рейтинг машины = среднее по отзывам), мета-теги и Open Graph для каждой машины (`api/meta.js`), страница 404 и состояние «ошибка загрузки» с кнопкой «Повторить».

**Админка:** дашборд (выручка, чек, загрузка парка, топ машин), отдельные аккаунты (владелец / менеджер), журнал действий, лимит попыток входа (8 с IP / 10 на логин за 15 минут), вкладка отзывов, кнопка «Дублировать» у машины.

**Технически:** расчёт суток и тарифов — один файл `supabase/functions/_shared/pricing.js`, его используют и сайт, и Edge Function. Тесты: `npm test` (14 штук, без новых зависимостей).

## Шаги

### 1. База
В SQL Editor выполните `supabase/migration_v3.sql` (один раз).
Если ругнётся на `ALTER TYPE` — выполните две первые команды отдельно, затем остальное.

### 2. Первый владелец (без этого в админку не войти!)
Общий пароль больше не работает — теперь логин + пароль. Выполните отдельным запросом:
```sql
insert into admin_users (username, password_hash, role)
values ('admin', crypt('ВАШ_НОВЫЙ_ПАРОЛЬ_от_8_символов', gen_salt('bf')), 'owner');
```
Остальных (менеджеров) создаёт владелец во вкладке «Пользователи».
Таблица `admin_config` больше не используется — её можно удалить.

### 3. Edge Functions
```bash
supabase functions deploy create-rental    --no-verify-jwt
supabase functions deploy admin-login      --no-verify-jwt
supabase functions deploy admin-api        --no-verify-jwt
supabase functions deploy telegram-webhook --no-verify-jwt
```

### 4. Telegram-кнопки
Придумайте длинную случайную строку (A–Z, a–z, 0–9, _ -) и сохраните как секрет:
```bash
supabase secrets set TELEGRAM_WEBHOOK_SECRET=ваша_строка
```
Затем включите webhook (подставьте токен бота, project-ref и ту же строку):
```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
  -d "url=https://<project-ref>.functions.supabase.co/telegram-webhook" \
  -d "secret_token=ваша_строка" \
  -d 'allowed_updates=["callback_query"]'
```
Секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` уже есть. Кнопки работают только в чате с этим `TELEGRAM_CHAT_ID`.

### 5. Vercel (превью ссылок в ВК)
Функция `api/meta.js` читает переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` — они уже заданы для сборки в проекте Vercel, ничего добавлять не нужно. После деплоя проверьте ссылку на машину в отладчике ВК. Старые превью ВК кеширует — обновите через отладчик.

### 6. Файлы
Скопируйте содержимое архива в проект. Затем `npm run dev` (новых зависимостей нет).

## Что можно удалить
- `src/data/categories.js` и `src/data/vehicles.js` — больше нигде не импортируются (карточка берёт категорию из БД).

## Важно знать
- Уже существующие заявки со статусом «Активна» после миграции считаются одобренными и показываются в календаре как занятые.
- Колонка `vehicles.is_rented` осталась в БД, но не используется: занятость считается по датам одобренных заявок.
- `supabase/schema.sql` не обновлялся. Для чистой установки: `schema.sql` → остальные миграции по порядку → `migration_v3.sql`.
- Текст на `/rules` («срок аренды — сутки или неделя») стоит поправить под гибкие даты — это текст в `RulesPage.jsx`, я его не трогал.
- Журнал не хранит пароли и ссылки на фото.
